# Marketing Notifications Preference Management Portal

**Client:** Major US-based telecom enterprise  
**Organization:** Amdocs Development Centre

Developed a customer self-service portal that allows telecom users to manage marketing communication preferences and notification subscriptions.

## Scope

- Designed backend APIs for consent management, notification preferences, and customer communication settings.
- Built responsive frontend interfaces using React and reusable components.
- Integrated frontend and backend systems through REST APIs.
- Optimized asynchronous data handling with React Query and Axios.
- Implemented unit and integration tests to support application stability and release quality.

## Product Outcome

The portal made consent and notification settings easier to manage for customers while giving business teams a maintainable platform for evolving communication preferences.

## Tech Stack

*Java* *Spring Boot* *React* *REST APIs* *React Query* *Axios* *JUnit* *Mockito* *Jest*
